# RE:SPCT — Respect in Every Click

A responsive and interactive gender-responsive digital platform for the Midterm Project.

## Central issue
Gender-based online sexual harassment.

## Files
- index.html — main website
- style.css — responsive design and styling
- script.js — navigation, animated statistics, modal, quiz, pledge, and back-to-top interaction

## How to run
1. Extract the ZIP file.
2. Open the `index.html` file in Google Chrome, Microsoft Edge, or another modern browser.
3. For editing, open the extracted folder in VS Code.
4. Keep `index.html`, `style.css`, and `script.js` in the same folder.

## Notes for submission
- The website uses official Philippine Commission on Women (PCW) and Philippine Statistics Authority (PSA) references.
- Internet access is needed for the Google Fonts import. The site still works without the font because fallback fonts are included.
- Before final submission, review the official source pages and update any statistics or legal wording if your instructor requires a particular citation format.
- Add your own name/course/section to the footer or homepage if required by your instructor.
